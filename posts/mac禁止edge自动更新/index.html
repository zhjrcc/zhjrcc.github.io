mac禁止edge自动更新

First published 2026-08-13
Modified 2026-08-13

Back↶

  1. /Library目录下新建一个Managed Preferences目录

  2. 在该目录中新建一个文件’com.microsoft.EdgeUpdater.plist’, 写入以下内容:

    updatePolicies global UpdateDefault 3

  3. 终端中输入, sudo chown root:wheel ‘/Library/Managed Preferences/com.microsoft.EdgeUpdater.plist’, 不报错就可以.报错就再根据报错信息检查plist文件.

  4. 输入 defaults write com.microsoft.Edge UpdatePolicyOverride -string manual-only, 这个输不输入都无所谓了, 在新版本中, 似乎不管用, 在低版本里有用.
